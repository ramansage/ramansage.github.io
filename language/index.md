# Language Learning Guides

Self-study grammar and vocabulary notes for **Korean** and **Swedish**, from beginner foundations through intermediate/advanced reading grammar.

## Korean (한국어)

| Level | Guide |
|-------|--------|
| Beginner | [Korean Learning Guide]({{ '/language/korean-learning-guide/' | relative_url }}) |
| Intermediate → Advanced | [Korean Intermediate → Advanced Grammar]({{ '/language/korean-intermediate-reading-guide/' | relative_url }}) |

- **Beginner:** Hangul, particles, conjugations, core vocab, dialogues  
- **Extension:** attitude endings, complex connectors, passive/causative, honorifics, manhwa & literature reading patterns  

## Swedish (Svenska)

| Level | Guide |
|-------|--------|
| Beginner | [Swedish Learning Guide]({{ '/language/swedish-learning-guide/' | relative_url }}) |
| Intermediate → Advanced | [Swedish Intermediate → Advanced Grammar]({{ '/language/swedish-intermediate-advanced-guide/' | relative_url }}) |

- **Beginner:** en/ett, V2, verbs, adjectives, core vocab, dialogues  
- **Extension:** bisats order, ju/väl/nog, passives, particle verbs, news & fiction reading  

## How to use

1. Start with the **beginner** guide for that language.  
2. Move to the **intermediate/advanced** file as an extension — it does not reteach the basics.  
3. Read with a notebook or Anki; mine example sentences, not isolated words only.
