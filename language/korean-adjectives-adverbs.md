# Korean Adjectives & Adverbs
### Descriptive Verbs (형용사) and Adverbs (부사) for Fluency

**Goal:** Expand beyond the beginner “most used” lists with **opposites, scales, collocations, and placement rules** so you can describe people, places, feelings, and actions more naturally.

**Prerequisites:** Hangul + basic ~아요/어요 conjugation from the [beginner guide]({{ '/language/korean-learning-guide/' | relative_url }}). For ranked core vocab, see the [high-frequency word list]({{ '/language/korean-high-frequency-words/' | relative_url }}).

**Remember:** Korean “adjectives” are **descriptive verbs**. They conjugate like verbs and **do not need 이다** in the predicate.

- 날씨가 좋아요. — The weather is good.  
- 이 책이 재미있어요. — This book is interesting.

---

## 1. How adjectives work (quick system)

### 1.1 Dictionary form → polite present

| Dictionary | Stem tip | 해요체 | English |
|------------|----------|--------|---------|
| 좋다 | 좋- | 좋아요 | is good |
| 크다 | 크- | 커요 | is big |
| 어렵다 | 어렵- (ㅂ→우) | 어려워요 | is difficult |
| 춥다 | 춥- (ㅂ→우) | 추워요 | is cold (weather) |
| 예쁘다 | 예쁘- (으 drop) | 예뻐요 | is pretty |
| 맛있다 | 맛있- | 맛있어요 | is delicious |
| 같다 | 같- | 같아요 | is the same / like |

### 1.2 Before a noun (modifier form)

| Tense feel | Pattern | Example |
|------------|---------|---------|
| Present descriptive | stem + (으)ㄴ | 좋은 사람, 큰 집 |
| 있다/없다 type | 있는 / 없는 | 맛있는 음식 |
| Past state | stem + (으)ㄴ (context) | 바쁜 하루 (busy day) |

- 예쁜 꽃 — a pretty flower  
- 재미있는 영화 — an interesting movie  
- 중요한 일 — important work  

### 1.3 좋다 vs 좋아하다

| Pattern | Meaning |
|---------|---------|
| N이/가 좋다 | N is good / I like N (ambiguous) |
| N을/를 좋아하다 | I like N (clear preference) |

- 커피가 좋아요. — Coffee is good. / I like coffee.  
- 커피를 좋아해요. — I like coffee.

## 3. Degree & scale (make descriptions precise)

### 3.1 Degree adverbs (before adjectives/verbs)

| Korean | Rom. | Strength | Notes |
|--------|------|----------|-------|
| 조금 / 좀 | jogeum / jom | slight | softener too |
| 약간 | yakgan | slight | a bit |
| 꽤 | kkwae | medium-high | quite |
| 아주 / 매우 | aju / maeu | high | very |
| 정말 / 진짜 | jeongmal / jinjja | high | really (jinjja = casual) |
| 너무 | neomu | high / excess | “so” or “too” |
| 엄청 / 되게 | eomcheong / doege | high | colloquial “super” |
| 완전(히) | wanjeon(hi) | total | completely |
| 전혀 | jeonhyeo | zero | with negation |
| 별로 | byeollo | low | with negation |
| 그리 | geuri | not that | with negation |
| 가장 / 제일 | gajang / jeil | superlative | most |
| 더 / 덜 | deo / deol | comparative | more / less |
| 훨씬 | hwolssin | comparative boost | much more |

**Patterns**
- 아주 좋아요. — It's very good.  
- 너무 비싸요. — It's too expensive.  
- 별로 안 매워요. — It's not particularly spicy.  
- 이게 훨씬 나아요. — This is much better.

### 3.2 Comparative & superlative shapes

| Meaning | Pattern | Example |
|---------|---------|---------|
| more A than B | B보다 (더) A | 커피가 차보다 더 좋아요. |
| the most | 제일/가장 A | 이 식당이 제일 맛있어요. |
| as … as | B만큼 A | 형만큼 커요. |
| not as … as | B만큼 A지 않다 | 저만큼 빠르지 않아요. |

## 7. Forming adverbs from adjectives

Many descriptive stems take **~게** for “-ly” manner.

| Adjective | Adverb | English |
|-----------|--------|---------|
| 쉽다 | 쉽게 | easily |
| 어렵다 | 어렵게 | with difficulty |
| 간단하다 | 간단하게 | simply |
| 조용하다 | 조용하게 | quietly |
| 행복하다 | 행복하게 | happily |
| 안전하다 | 안전하게 | safely |
| 특별하다 | 특별하게 | specially |
| 빠르다 | 빠르게 | quickly (also 빨리) |
| 느리다 | 느리게 | slowly |
| 정확하다 | 정확하게 | accurately |
| 친절하다 | 친절하게 | kindly |

- 쉽게 설명해 주세요. — Please explain it simply/easily.  
- 조용하게 말해 주세요. — Please speak quietly.

Some set forms are preferred: **빨리** (more common than 빠르게 in speech), **잘**, **많이**.

## 8. Mini dialogues (adjective + adverb focus)

### 8.1 Weather & plans

**A:** 오늘 날씨 어때요?  
**B:** 정말 좋아요. 따뜻하고 맑아요.  
**A:** 그러면 공원에 같이 갈까요?  
**B:** 좋아요. 조금 나중에 만나요.

### 8.2 Food

**A:** 이 김치 매워요?  
**B:** 조금 매워요. 별로 안 짜요.  
**A:** 맛있어요?  
**B:** 네, 아주 맛있어요!

### 8.3 Work / study

**A:** 요즘 어때요?  
**B:** 너무 바빠요. 매일 늦게 끝나요.  
**A:** 힘들겠어요.  
**B:** 네, 그래도 열심히 하고 있어요.
