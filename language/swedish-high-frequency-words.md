# Swedish High-Frequency Word List
### Core Vocabulary by Usefulness (Beginner → Lower Intermediate)

**Goal:** A **drillable frequency-first word bank** that complements the [beginner guide]({{ '/language/swedish-learning-guide/' | relative_url }}) and [intermediate grammar]({{ '/language/swedish-intermediate-advanced-guide/' | relative_url }}). Those teach *how* Swedish works; this page is **what to learn first**.

**How to use**
1. Work in **bands** (A → E). 10–15 items/day + one sentence about *your* life.
2. Always learn **en/ett** with nouns.
3. For verbs: store **infinitive + present + past** (and supine when you can).
4. Revisit Band A weekly — function words run every sentence.
5. Speak aloud; Swedish spelling ≠ sound.

**Notation**

| Symbol | Meaning |
|--------|---------|
| **en / ett** | Common / neuter gender |
| (v) (n) (adj) (adv) | Part of speech |
| *present / past* | Quick conjugation hint |

> Order is **learner-priority frequency** (conversation + simple media), not a pure corpus dump.

| Day | Focus |
|-----|--------|

| 3 | Question words + V2 questions |
| 4–5 | Band B verbs (half each day) with present/past |
| 6 | Band C people + time |
| 7 | Band C places |
| 8 | Band C things/food |
| 9 | Band D connectors/adverbs |
| 10 | Band E numbers + clock |
