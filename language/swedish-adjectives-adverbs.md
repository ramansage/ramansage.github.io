# Swedish Adjectives & Adverbs
### Agreement, Scales, Opposites, and Natural Placement

**Goal:** Go beyond the beginner “most used” lists with **agreement drills, opposites, degree scales, sentence adverbs, and collocations** so descriptions sound Swedish, not word-for-word English.

**Prerequisites:** en/ett + basic V2 from the [beginner guide]({{ '/language/swedish-learning-guide/' | relative_url }}). For ranked core vocab, see the [high-frequency word list]({{ '/language/swedish-high-frequency-words/' | relative_url }}).

---

## 1. Adjective agreement (the system you must own)

### 1.1 Indefinite forms

| | en-word | ett-word | Plural |
|--|---------|----------|--------|
| Pattern | base | often **+t** | often **+a** |
| big | en stor bil | ett stort hus | stora bilar / hus |
| good | en bra bok | ett bra jobb | bra böcker |
| new | en ny bil | ett nytt hus | nya bilar |
| old | en gammal man | ett gammalt hus | gamla hus |
| little | en liten hund | ett litet barn | små barn |

**Irregular must-knows**
- liten → litet → **små** (plural)
- gammal → gammalt → gamla
- bra stays **bra** in all indefinite forms (pl. also bra)

### 1.2 Definite forms (double definite)

When adjective + definite noun:

**den/det/de + adjective-a + definite noun**

| English | Swedish |
|---------|---------|
| the big car | den stora bilen |
| the big house | det stora huset |
| the big cars | de stora bilarna |
| my new book | min nya bok |
| this old house | det här gamla huset |

### 1.3 Predicate adjectives

After *vara, bli, verka, kännas…* agree with the subject:

- Bilen är stor.  
- Huset är stort.  
- Bilarna är stora.  
- Barnen är små.

## 3. Comparatives & superlatives

### 3.1 Regular pattern (-are / -ast)

| Base | Comparative | Superlative | English |
|------|-------------|-------------|---------|
| billig | billigare | billigast | cheap |
| snabb | snabbare | snabbast | fast |
| glad | gladare | gladast | happy |
| intressant | intressantare | intressantast | interesting |

Definite superlative often: **den/det/de + -aste**  
- den billigaste bilen — the cheapest car

### 3.2 Irregular (memorize)

| Base | Comp. | Superl. | English |
|------|-------|---------|---------|
| bra | bättre | bäst | good |
| dålig | sämre | sämst | bad |
| liten | mindre | minst | small |
| stor | större | störst | big |
| få | färre | färst | few |
| många | fler | flest | many |
| gammal | äldre | äldst | old |
| ung | yngre | yngst | young |
| tung | tyngre | tyngst | heavy |
| lång | längre | längst | long |
| hög | högre | högst | high |
| låg | lägre | lägst | low |

### 3.3 Patterns in sentences

| Meaning | Pattern | Example |
|---------|---------|---------|
| more … than | -are än | Hon är snabbare än jag. |
| as … as | lika … som | Han är lika long som sin bror. |
| not as … as | inte lika … som | Det är inte lika dyrt som förut. |
| the most | -ast / mest + adj | Det är bäst. / mest intressant |
| more + long adj | mer + adj | mer spännande |

Some longer adjectives use **mer / mest**:  
- mer komplicerad, mest komplicerad

## 4. Degree adverbs (scale your meaning)

| Swedish | Strength | English |
|---------|----------|---------|
| lite / en aning | slight | a little |
| ganska | medium | quite |
| rätt | medium | rather / fairly |
| mycket / väldigt | high | very |
| jätte- (prefix) | high | super (jättebra) |
| extremt / otroligt | high | extremely / incredibly |
| för | excess | too |
| så | high | so |
| helt | total | completely |
| alldeles | total | entirely |
| nästan | near total | almost |
| absolut | total | absolutely |
| särskilt / speciellt | focus | especially |
| mer / mest | comparative | more / most |
| mindre / minst | comparative | less / least |
| mycket mer | boost | much more |

**Examples**
- Det är ganska kallt. — It's quite cold.  
- Kaffet är för hett. — The coffee is too hot.  
- Filmen var jättebra. — The film was really good.  
- Hon är mycket snällare än jag trodde. — She is much kinder than I thought.

## 6. Sentence adverbs (satsadverbial) — placement power

In **main clauses**, sentence adverbs usually sit **after the finite verb** (and often after a short subject):

- Jag **äter inte** kött.  
- Hon **kan tyvärr inte** komma.  
- Det **är faktiskt** sant.

In **subordinate clauses**, they come **before** the verb:

- … att hon **inte kan** komma.  
- … eftersom det **faktiskt är** sant.

### High-value sentence adverbs

| Swedish | Feel / English |
|---------|----------------|
| inte | not |
| aldrig | never |
| alltid | always |
| också | also |
| bara | only |
| redan | already |
| fortfarande | still |
| kanske | maybe |
| tyvärr | unfortunately |
| egentligen | actually / really (deeper) |
| faktiskt | actually / in fact |
| verkligen | really |
| absolut | absolutely |
| naturligtvis / givetvis | of course |
| antagligen / förmodligen | probably |
| säkert | surely / safely |
| nog | probably / I suppose |
| ju | as you know / softening |
| väl | I suppose / tag question feel |
| alltså | so / that means |
| ändå | still / even so |
| däremot | on the other hand |
| därför | therefore |
| dessutom | furthermore |
| exempelvis | for example |
| särskilt | especially |
| ungefär | approximately |
| precis | exactly |
| helt enkelt | simply |

**Particle trio (very Swedish):** *ju, väl, nog* — learn with whole sentences.  
- Det är **ju** uppenbart. — It's obvious (as we both know).  
- Du kan **väl** hjälpa mig? — You can help me, right?  
- Det tar **nog** en timme. — It'll probably take an hour.

More on stacking and bisats order → [intermediate guide]({{ '/language/swedish-intermediate-advanced-guide/' | relative_url }}).

## 8. Mini dialogues

### 8.1 Weather

**A:** Hur är vädret i dag?  
**B:** Det är ganska kallt, men soligt.  
**A:** Ska vi gå ut ändå?  
**B:** Ja, gärna. Det är bättre än att sitta inne.

### 8.2 Food

**A:** Är soppan god?  
**B:** Ja, den är jättegod — lite salt, men inte för stark.  
**A:** Perfekt. Jag är väldigt hungrig.

### 8.3 Plans

**A:** Är du upptagen i morgon?  
**B:** Tyvärr ja. Jag måste jobba sent.  
**A:** Vad synd. Vi ses hellre i helgen?  
**B:** Absolut. Det blir bäst.
